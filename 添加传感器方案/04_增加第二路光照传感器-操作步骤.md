# 增加第二个光照传感器（GY-302 / BH1750 #2）· 操作步骤

> 适用工程：`D:\水循环\YF-S401_flow`
> 现状：D21（SDA）/ D22（SCL）上挂了一个 GY-302，地址 0x23
> 目标：再加一路光照，**共用同一条 I2C 总线**，提供 `/api/light2`

---

## 关键：不用多占引脚，靠地址区分

I2C 是**总线式**的，同一条线上可以挂很多个器件，靠**地址**区分。BH1750 有两个可选地址：

| ADDR 脚接法 | I2C 地址 |
|------------|---------|
| 悬空 或 接 GND | **0x23**（你第一路用的） |
| 接 VCC | **0x5C** |

所以第二个模块**只要把 ADDR 接到 3.3V**，就能和第一个挂在同一条 D21/D22 上互不冲突，**一个引脚都不用多占**。

---

## 第 1 步：接线

第二个 GY-302 模块：

| 模块脚 | 接到哪里 |
|--------|---------|
| VCC | 3.3V |
| GND | GND |
| SDA | **D21**（和第一个并联） |
| SCL | **D22**（和第一个并联） |
| **ADDR** | **3.3V** ← 关键！改地址为 0x5C |

> 两个模块的 SDA 接同一根线、SCL 接同一根线，电源并联即可。总线上的上拉电阻模块自带了，不用再外接。

## 第 2 步：新建 light_sensor2.cpp

复制 `light_sensor.cpp`，重命名为 **`light_sensor2.cpp`**，内容整个替换为：

```cpp
// ============================================================
// 第二路光照传感器模块（GY-302 / BH1750 #2）
// 与第一路共用 I2C 总线（D21 SDA / D22 SCL），靠地址区分：
//   第一路 ADDR 悬空 = 0x23    第二路 ADDR 接 VCC = 0x5C
//
// 注意：这里不再调用 Wire.begin()，总线已在第一路初始化过了
// ============================================================
#include "config.h"

// 下面两个指令常量在 light_sensor.cpp 里是文件内私有的，这里要重新定义一份
#define BH1750_POWER_ON 0x01      // 上电（上电默认是掉电模式，必须先发这条）
#define BH1750_CONT_H_RES 0x10    // 连续高分辨率模式，1 lx，约 120ms 一次

static uint8_t lightAddr2 = LIGHT_ADDR_ALT;   // 第二个模块固定用 0x5C
static bool lightFound2 = false;
static unsigned long lastLightMs2 = 0;

// 发一条单字节指令，返回是否成功
static bool lightWrite2(uint8_t cmd) {
  Wire.beginTransmission(lightAddr2);
  Wire.write(cmd);
  return Wire.endTransmission() == 0;
}

void initLightSensor2() {
  lastLux2 = 0.0;
  lightOk2 = false;
  lightFound2 = false;

  // 探测 0x5C 上有没有器件应答（不重复 Wire.begin，总线已由第一路初始化）
  Wire.beginTransmission(lightAddr2);
  if (Wire.endTransmission() != 0) {
    Serial.printf("GY-302 #2 未检测到（地址 0x%02X）：检查模块 ADDR 是否接到 3.3V，"
                  "以及 SDA/SCL 是否并联到 D%d/D%d\n",
                  lightAddr2, LIGHT_SDA_PIN, LIGHT_SCL_PIN);
    return;
  }

  lightWrite2(BH1750_POWER_ON);
  delay(10);                       // 等芯片进入上电状态
  lightWrite2(BH1750_CONT_H_RES);
  lightFound2 = true;
  lastLightMs2 = millis();         // 第一帧转换约 120ms，1 秒后再读

  Serial.printf("GY-302 #2 光照传感器初始化完成（I2C 0x%02X，共用 D%d/D%d）\n",
                lightAddr2, LIGHT_SDA_PIN, LIGHT_SCL_PIN);
}

// 非阻塞轮询：主循环每圈调用一次
void processLightSensor2() {
  if (!lightFound2) return;

  unsigned long now = millis();
  if (now - lastLightMs2 < LIGHT_READ_INTERVAL_MS) return;
  lastLightMs2 = now;

  Wire.requestFrom((uint8_t)lightAddr2, (uint8_t)2);
  if (Wire.available() < 2) {
    lightOk2 = false;
    return;
  }

  uint16_t raw = ((uint16_t)Wire.read() << 8) | (uint16_t)Wire.read();
  lastLux2 = raw / 1.2;
  lightOk2 = true;
}
```

> ⚠️ 顺序很重要：`initLightSensor()`（第一路）必须在 `initLightSensor2()` **之前**调用，因为总线是它初始化的。主文件里保持这个顺序即可。

## 常见坑

| 现象 | 原因 |
|------|------|
| `#2 未检测到（地址 0x5C）` | ① ADDR 没接 3.3V ② SDA/SCL 没并联 ③ 模块本身是坏的 |
| 两路读数**永远一模一样** | 两个模块地址相同（都 0x23），说明第二个的 ADDR 没接 VCC，总线上地址冲突 |
| 第一路也失效了 | 检查 SDA/SCL 有没有接反，或接线松动导致总线被拉死 |
| `Wire` 未定义 | `config.h` 里已经 `#include <Wire.h>`，确认没删掉 |
| 读数跳得厉害 | I2C 线太长；把线缩短，或降低 `Wire.setClock` 的速度 |

> 如果两个模块的 ADDR 都无法改动（有些模块 ADDR 是焊死的），那就只能给第二路单独开一条 I2C 总线（ESP32 的 `Wire1`，另选两个引脚）。那种情况告诉我，我另给一份方案。

# 增加第三路继电器 · 操作步骤

> 适用工程：`D:\水循环\YF-S401_flow`
> 现状：已有 **D32**（继电器 1 / 水泵）和 **D14**（继电器 2 / 水泵2）
> 目标：再加一路继电器，接 **D17**，提供 `/api/relay3/on` 等接口

---

## 继电器和传感器不一样的地方

继电器**不需要在 `loop()` 里轮询**——它只在"你点按钮 / 调接口"的时候动一下。所以只改 4 个地方：

1. 新建 `relay3.cpp`
2. 改 `config.h`
3. 改主文件（**只需要定义变量 + `setup()` 里初始化**，`loop` 不用动）
4. 改 `web_server.cpp`（可选，要接口和网页按钮才做）

---

## 第 1 步：选引脚

**推荐 D17。**

你现在的引脚占用情况：

| 已占用 | 用途 |
|--------|------|
| D34 | 流量 1 |
| D32 | 继电器 1（水泵） |
| **D14** | **继电器 2（水泵2）** |
| D26 | 加热继电器 |
| D27 / D25 | 水温 1 / 2 |
| D33 | 压力 |
| D23 / D18 | 超声波 Trig / Echo |
| D21 / D22 | 光照 I2C |

继电器 IN 是**数字输出**信号，要求：**双向 GPIO、不能是 D34~D39**（输入专用脚）。

可用清单：

| 引脚 | 说明 |
|------|------|
| **D17** | **推荐**。注意：如果你的板子是带 PSRAM 的 **WROVER** 型号，D16/D17 被 PSRAM 占用，**不能用** |
| D4 / D13 | 如果没给超声波 #2 用，可以用 |
| D16 | 如果没给加热继电器 #2 用，可以用（WROVER 同样不能用） |
| D19 | 如果没给流量计 #2 用，可以用 |
| ~~D5~~ | ❌ **不要用**。D5 是 strapping 启动脚，要求上电为高电平，而继电器 IN 上电时是低电平/悬空，会**影响 ESP32 启动** |
| ~~D0 / D2 / D12 / D15~~ | ❌ 其他 strapping 脚，避开 |
| ~~D6~D11~~ | ❌ 接内部 Flash，绝对不能用 |

> 判断原则：从上面挑一个**当前代码里没出现过**的号。你可以在 `config.h` 里搜一下想用的引脚号，确认没被占用。
>
> 注意：照 00 总览的完整规划全加完之后，**双向脚就基本用满了**，第三路继电器建议尽早接。

## 第 2 步：接线

| 继电器端子 | 接到哪里 |
|-----------|---------|
| **DC+** | **5V**（或按模块额定电压；5V 模块千万别接 12V） |
| **DC-** | GND（**必须和 ESP32 共地**，否则继电器乱跳） |
| **IN** | **D17** |

负载侧（第三路控制的设备，按你的实际用途接）：

- 负载电源正 → 继电器 **COM**
- 继电器 **NO** → 负载正极
- 负载负极 → 负载电源负极
- **NC 空着不接**

⚠️ **负载电源必须独立**，不要从 ESP32 的 5V 引脚取电（水泵、加热这类大电流负载尤其不能）。

⚠️ **跳线帽要和代码里的极性宏一致**：跳线帽在 **H**（高电平触发）→ `RELAY3_ACTIVE_HIGH` 写 `1`；在 **L** → 写 `0`。

> 可选加固：在 IN 和 GND 之间加一个 **10kΩ 下拉电阻**，可以避免上电瞬间继电器抖一下。

## 第 3 步：新建 relay3.cpp

在文件夹 `D:\水循环\YF-S401_flow` 里，复制 `relay2.cpp`，重命名为 **`relay3.cpp`**，内容整个替换为：

```cpp
// ============================================================
// 第三路继电器控制模块（D17）
// 负责：初始化（上电默认关）和按触发极性开关第三路负载
//
// 接线：DC+ -> 5V（或模块额定电压），DC- -> GND（必须和 ESP32 共地），IN -> D17
//       负载电源独立，接继电器 COM/NO，不要从 ESP32 取电
//       ⚠️ 跳线帽极性和 RELAY3_ACTIVE_HIGH 必须一致（H 对应 1，L 对应 0）
// ============================================================
#include "config.h"

void initRelay3() {
  pinMode(RELAY3_PIN, OUTPUT);
  setRelay3(false);         // 上电默认关闭
  Serial.println("继电器 #3 初始化完成（D17，上电默认关闭）");
}

// 控制第三路继电器开关（按 RELAY3_ACTIVE_HIGH 极性）
void setRelay3(bool on) {
  relay3State = on;
#if RELAY3_ACTIVE_HIGH
  digitalWrite(RELAY3_PIN, on ? HIGH : LOW);
#else
  digitalWrite(RELAY3_PIN, on ? LOW : HIGH);
#endif
  Serial.printf("继电器3%s\n", on ? "已开启" : "已关闭");
}
```

> 如果第三路也是**水泵**，可以把名字改成 `setPump3` / `pumpState3` / `/api/pump3/*`，命名风格和你已有的两路一致——功能上完全没区别，只是叫法不同。本文档统一用通用的 `relay3`。

## 第 6 步：改 web_server.cpp（要接口和按钮才做）

### 6.1 handleData() 里加字段

找到：

```cpp
  json += "\"pump2\":" + String(pumpState2 ? "true" : "false") + ",";
```

在它下面加：

```cpp
  json += "\"relay3\":" + String(relay3State ? "true" : "false") + ",";
```

> 同样可以在 `handleHealth()` 里加一份，非必须。

### 6.2 新增四个接口函数

找到 `handlePump2State()` 那个函数，在它下面加：

```cpp
// GET /api/relay3/on —— 开第三路继电器
void handleRelay3On() {
  setRelay3(true);
  sendJson(200, "{\"status\":\"ok\",\"relay3\":true}");
}

// GET /api/relay3/off —— 关第三路继电器
void handleRelay3Off() {
  setRelay3(false);
  sendJson(200, "{\"status\":\"ok\",\"relay3\":false}");
}

// GET /api/relay3/toggle —— 切换第三路继电器
void handleRelay3Toggle() {
  setRelay3(!relay3State);
  String json = "{\"status\":\"ok\",\"relay3\":" + String(relay3State ? "true" : "false") + "}";
  sendJson(200, json);
}

// GET /api/relay3/state —— 查询第三路继电器状态
void handleRelay3State() {
  String json = "{\"relay3\":" + String(relay3State ? "true" : "false") + "}";
  sendJson(200, json);
}
```

### 6.3 registerRoutes() 里注册

找到：

```cpp
  server.on("/api/pump2/state", handlePump2State);
```

在它下面加：

```cpp
  server.on("/api/relay3/on", handleRelay3On);
  server.on("/api/relay3/off", handleRelay3Off);
  server.on("/api/relay3/toggle", handleRelay3Toggle);
  server.on("/api/relay3/state", handleRelay3State);
```

### 6.4 网页按钮

**（1）按钮和状态行** —— 在 `handleRoot()` 里，找到：

```cpp
  html += "<button onclick=\"doPump2(0)\">关水泵2</button></p>";
```

在它下面加：

```cpp
  html += "<p>继电器3状态：<b id='relay3'>--</b></p>";
  html += "<button onclick=\"doRelay3(1)\">开继电器3</button> ";
  html += "<button onclick=\"doRelay3(0)\">关继电器3</button></p>";
```

**（2）显示更新** —— 放进 `refresh()` 里面。找到：

```cpp
          "p2el.innerText=d.pump2?'运行中':'已停止';p2el.style.color=d.pump2?'green':'red';"
```

在它下面加：

```cpp
          "var r3=document.getElementById('relay3');"
          "r3.innerText=d.relay3?'运行中':'已停止';r3.style.color=d.relay3?'green':'red';"
```

**（3）控制函数** —— 必须放在 `refresh()` 函数**外面**。找到：

```cpp
          "function doPump2(on){fetch('/api/pump2/'+(on?'on':'off')).then(refresh);}"
```

在它旁边加：

```cpp
          "function doRelay3(on){fetch('/api/relay3/'+(on?'on':'off')).then(refresh);}"
```

> ⚠️ **为什么第 (3) 步必须放在外面**：网页按钮用的是 `onclick="doRelay3(1)"`，它只能调用**全局函数**。如果混在 `refresh()` 里面，函数就只在那个回调内部可见，按钮点击会报 `doRelay3 is not defined`，**点了完全没反应**。
> 判断方法：`function doPump(...)`、`function doPump2(...)` 这两行的位置就是"外面"，加在它们旁边才对。

## 常见坑

| 现象 | 原因 |
|------|------|
| 代码打印"已开启"但继电器不咔哒 | ① DC+ 电压不够或没接 ② 跳线帽极性和 `RELAY3_ACTIVE_HIGH` 反了 ③ IN 线没接对脚 |
| 继电器一直吸合、关不掉 | 极性反了：把 `RELAY3_ACTIVE_HIGH` 的 1 改成 0（或跳线帽从 H 拨到 L） |
| 继电器随机乱跳 | **没共地**（继电器 DC- 和 ESP32 GND 必须接一起） |
| 一开负载板子就重启 | 负载从 ESP32 取电了，必须用独立电源 |
| 网页按钮点了没反应，但直接访问网址能动作 | JS 的 `function doRelay3(...)` 加进了 `refresh()` 里面，要挪到外面（见 6.4 第 (3) 步） |
| 板子开不了机 / 反复重启 | 引脚选到了 strapping 脚（尤其 D5）且上电电平不对，换 D17 等普通脚 |
| 编译报 `redefinition` | 复制文件后变量名/函数名没全改成 `3` 后缀 |
| 编译报 `undefined reference to 'relay3State'` | `config.h` 里声明了，但主文件没定义（见 5.1） |

## 检查清单

- [ ] 继电器 IN 接 D17，DC+ 接对电压，DC- 和 ESP32 共地
- [ ] 跳线帽位置和 `RELAY3_ACTIVE_HIGH` 一致（H 对应 1，L 对应 0）
- [ ] 负载用独立电源，接 COM/NO，NC 空着
- [ ] 新建 `relay3.cpp`，所有名字带 `3` 后缀
- [ ] `config.h` 加了 `RELAY3_PIN`、`RELAY3_ACTIVE_HIGH`、1 个 extern、2 个函数声明、4 个接口声明
- [ ] 主文件加了 `relay3State` 全局变量、`initRelay3()`（**loop 不用改**）
- [ ] `web_server.cpp` 加了 JSON 字段、4 个接口函数、4 条路由
- [ ] 网页 JS 的 `doRelay3` 放在 `refresh()` **外面**
- [ ] 串口出现 `继电器 #3 ... 初始化完成`
- [ ] 点按钮 / 调接口能听到继电器咔哒声，方向正确

# 增加第二路水泵继电器 · 操作步骤

> 适用工程：`D:\水循环\YF-S401_flow`
> 现状：已有 D32（水泵继电器 1）
> 目标：再加一路继电器控制第二个水泵，接 **D14**，提供 `/api/pump2/on` 等接口

---

## 继电器的特点和传感器不一样

继电器**不需要在 `loop()` 里轮询**——它只在"你点按钮/调接口"的时候动一下。所以少一个步骤，只改 4 个地方：

1. 新建 `relay2.cpp`
2. 改 `config.h`
3. 改主文件（**只需要定义变量 + `setup()` 里初始化**，loop 不用动）
4. 改 `web_server.cpp`（可选，要接口才做）

---

## 第 1 步：选引脚

继电器 IN 是**数字输出**信号，任意**双向 GPIO** 都行，但不能是 D34~D39（输入专用脚，不能输出）。

**推荐 D14。**

其他可用：D4、D5、D13、D16、D17、D19

避开：D0 / D2 / D12 / D15（启动脚，上电瞬间电平会影响 ESP32 启动）、D6~D11（接内部 Flash，绝对不能用）。

---

## 第 2 步：接线

以 WKY-1-RELAY-1 为例：

| 继电器端子 | 接到哪里 |
|-----------|---------|
| **DC+** | **5V**（必须 5V，3.3V 吸合不了；也可以用独立电源，但负极要和 ESP32 共地） |
| **DC-** | GND（**必须共地**，否则继电器乱跳） |
| **IN** | **D14** |

负载侧（水泵回路）：

- 水泵电源正 → 继电器 **COM**
- 继电器 **NO** → 水泵正极
- 水泵负极 → 水泵电源负极
- **NC 空着不接**

⚠️ **水泵电源必须独立**，绝对不要从 ESP32 的 5V 引脚取电，否则一开泵板子就复位。

⚠️ **跳线帽要和代码里的极性宏一致**：跳线帽在 **H**（高电平触发）→ 代码里 `RELAY2_ACTIVE_HIGH` 写 `1`；跳线帽在 **L** → 写 `0`。

---

## 第 3 步：新建 relay2.cpp

复制 `relay.cpp`，重命名为 **`relay2.cpp`**，内容整个替换为：

```cpp
// ============================================================
// 第二路继电器 / 水泵控制模块（D14）
// 负责：初始化（上电默认关）和按触发极性开关第二个水泵
// ============================================================
#include "config.h"

void initRelay2() {
  pinMode(RELAY2_PIN, OUTPUT);
  setPump2(false);          // 上电默认关闭
  Serial.println("继电器水泵 #2 初始化完成（D14，上电默认关闭）");
}

// 控制第二个水泵开关（按 RELAY2_ACTIVE_HIGH 极性）
void setPump2(bool on) {
  pumpState2 = on;
#if RELAY2_ACTIVE_HIGH
  digitalWrite(RELAY2_PIN, on ? HIGH : LOW);
#else
  digitalWrite(RELAY2_PIN, on ? LOW : HIGH);
#endif
  Serial.printf("水泵2%s\n", on ? "已开启" : "已关闭");
}
```

## 第 4 步：改 config.h

### 4.1 加引脚宏和变量声明

找到水泵继电器那一段（`extern bool pumpState;` 附近），在下面加：

```cpp
// ---------------- 继电器水泵 #2 ----------------
#define RELAY2_PIN 14            // D14，第二个继电器的 IN
#define RELAY2_ACTIVE_HIGH 1     // 1=高电平触发(跳线帽在H)；0=低电平触发(跳线帽在L)
extern bool pumpState2;          // 水泵2 当前状态：true=开
```

### 4.2 加函数声明

找到：

```cpp
// 继电器模块
void initRelay();
void setPump(bool on);
```

在下面加：

```cpp
// 第二路继电器模块
void initRelay2();
void setPump2(bool on);
```

### 4.3 加接口声明（做第 6 步才需要）

```cpp
void handlePump2On();
void handlePump2Off();
void handlePump2Toggle();
void handlePump2State();
```

## 第 6 步：改 web_server.cpp（要接口才做）

**6.1 handleData() 里加字段**（在 `"pump"` 那行后面）

```cpp
  json += "\"pump2\":" + String(pumpState2 ? "true" : "false") + ",";
```

**6.2 新增四个接口函数**（在 `handlePumpTarget()` 下面）

```cpp
// GET /api/pump2/on —— 开第二个水泵
void handlePump2On() {
  setPump2(true);
  sendJson(200, "{\"status\":\"ok\",\"pump2\":true}");
}

// GET /api/pump2/off —— 关第二个水泵
void handlePump2Off() {
  setPump2(false);
  sendJson(200, "{\"status\":\"ok\",\"pump2\":false}");
}

// GET /api/pump2/toggle —— 切换第二个水泵
void handlePump2Toggle() {
  setPump2(!pumpState2);
  String json = "{\"status\":\"ok\",\"pump2\":" + String(pumpState2 ? "true" : "false") + "}";
  sendJson(200, json);
}

// GET /api/pump2/state —— 查询第二个水泵状态
void handlePump2State() {
  String json = "{\"pump2\":" + String(pumpState2 ? "true" : "false") + "}";
  sendJson(200, json);
}
```

**6.3 registerRoutes() 里注册**（在 `/api/pump/target` 那行附近）

```cpp
  server.on("/api/pump2/on", handlePump2On);
  server.on("/api/pump2/off", handlePump2Off);
  server.on("/api/pump2/toggle", handlePump2Toggle);
  server.on("/api/pump2/state", handlePump2State);
```

**6.4 网页按钮（可选）**

在 `handleRoot()` 里加：

```cpp
  html += "<p>水泵2状态：<b id='pump2'>--</b></p>";
  html += "<button onclick=\"doPump2(1)\">开水泵2</button> ";
  html += "<button onclick=\"doPump2(0)\">关水泵2</button></p>";
```

JS 要分**两个地方**加（⚠️ 加错位置按钮会点不动，见下面的说明）：

**（1）显示更新** —— 放进 `refresh()` 里面。找到 `var p=document.getElementById('pump');` 那两行，在下面加：

```cpp
          "var p2=document.getElementById('pump2');"
          "p2.innerText=d.pump2?'运行中':'已停止';p2.style.color=d.pump2?'green':'red';"
```

**（2）控制函数** —— 必须放在 `refresh()` 函数**外面**。找到 `function doPump(on){...}` 那一行，在它旁边加：

```cpp
          "function doPump2(on){fetch('/api/pump2/'+(on?'on':'off')).then(refresh);}"
```

> ⚠️ **为什么必须分开写**：网页按钮用的是 `onclick="doPump2(1)"`，它只能调用**全局函数**。如果把 `function doPump2` 混在上面那一段里，它就被定义在 `refresh()` 的回调函数**内部**了，只在回调内部可见——按钮点击时会报 `doPump2 is not defined`，**点了完全没反应**。
>
> 判断方法：`function doPump(...)`、`function doHeater(...)` 这几行在代码里的位置，就是"外面"，加在它们旁边才对。

## ⚠️ 和「定量浇水自动关泵」的关系

你主文件 `flow_sensor.cpp` 里的 `sampleFlow()` 有这段逻辑：累计水量达到设定值就 `setPump(false)` 关掉**第一路**水泵。

**它不会自动关第二路水泵。** 如果你希望"定量浇水到达目标时两个泵都停"，要在 `flow_sensor.cpp` 的 `sampleFlow()` 里那段后面补一行：

```cpp
      setPump(false);
      setPump2(false);          // ← 补这一行，两个泵一起停
      Serial.println("已达到设定水量，自动关闭水泵");
```

如果第二路泵是独立用途（比如另一条支路），那就保持现状，不用改。

## 常见坑

| 现象 | 原因 |
|------|------|
| 代码打印"已开启"但继电器不咔哒 | ① DC+ 没接 5V ② 跳线帽极性和 `RELAY2_ACTIVE_HIGH` 反了 ③ IN 线没接对脚 |
| 继电器一直吸合、关不掉 | 极性反了：把 `RELAY2_ACTIVE_HIGH` 的 1 改成 0（或跳线帽从 H 拨到 L） |
| 继电器随机乱跳 | **没共地**（继电器 DC- 和 ESP32 GND 必须接一起） |
| 一开水泵2 板子就重启 | 水泵从 ESP32 取电了，必须用独立电源 |
| 上电瞬间水泵抖一下 | 该引脚上电时是悬空的，可在 IN 到 GND 之间加一个 10kΩ 下拉电阻 |

## 检查清单

- [ ] 继电器 IN 接 D14，DC+ 5V，DC- 和 ESP32 共地
- [ ] 跳线帽位置和 `RELAY2_ACTIVE_HIGH` 一致（H 对应 1，L 对应 0）
- [ ] 新建 `relay2.cpp`，名字带 `2` 后缀
- [ ] config.h 加了 `RELAY2_PIN`、`RELAY2_ACTIVE_HIGH`、1 个 extern、2 个函数声明
- [ ] 主文件加了 `pumpState2` 全局变量、`initRelay2()`（**loop 不用改**）
- [ ] 串口出现 `继电器水泵 #2 ... 初始化完成`
- [ ] 点接口能听到继电器咔哒声

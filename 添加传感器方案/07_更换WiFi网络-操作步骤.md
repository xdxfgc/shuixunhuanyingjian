# 更换 WiFi 网络 · 操作步骤

> 适用工程：`D:\水循环\YF-S401_flow`
> 场景：换路由器、换场地、去比赛现场，ESP32 要连到新的 WiFi

> ⚠️ **安全提醒**：不要把**真实的 WiFi 密码**提交到 GitHub 公开仓库。仓库里建议写占位符（如 `"你的WiFi名字"`），真实密码只留在本地；或者把仓库设为私有。

## 二、⚠️ 最容易犯的错：IP 地址的写法

**IP 地址必须写成"四个数字用逗号分开"，不能写成 `192.168.1.100` 这种带点的形式。**

| | 写法 | 结果 |
|---|------|------|
| ✅ **正确** | `IPAddress LOCAL_IP(192, 168, 1, 100);` | 地址 = 192.168.1.100 |
| ❌ **错误** | `IPAddress LOCAL_IP(192.168.1.100);` | 编译器把它当成**小数** 192.1681，只取整数部分 **192**，实际地址变成 **0.0.0.192** |

**为什么？** `IPAddress(...)` 的构造函数要求四段分开传入。写成 `192.168.1.100` 时，C++ 会把它解析成一个浮点数，再偷偷转换成整数 192——**能编译通过，但地址完全是错的**，ESP32 会拿到一个无效的 IP，网络不通。

**三个必须用逗号分隔的**：`LOCAL_IP`、`GATEWAY`、`DNS1`。

> 另一种正确写法是字符串形式：`IPAddress LOCAL_IP("192.168.1.100");`（带引号）。这种也可以，但要注意**引号不能漏**。

## 三、新网络该填什么

### 第 1 步：把电脑连上新 WiFi

### 第 2 步：查"默认网关"

打开 **CMD 或 PowerShell**，输入：

```
ipconfig
```

找到正在用的网卡（无线一般是 `Wireless LAN adapter WLAN`），看这三行：

| 项目 | 例子 |
|------|------|
| IPv4 Address | 192.168.1.35 |
| Subnet Mask | 255.255.255.0 |
| **Default Gateway** | **192.168.1.1** ← 这个就是网关 |

### 第 3 步：按网关填代码

假设网关是 `192.168.1.1`：

| 配置项 | 填什么 |
|--------|--------|
| GATEWAY | `192, 168, 1, 1`（和网关完全一致） |
| DNS1 | `192, 168, 1, 1`（一般就用网关） |
| SUBNET | `255, 255, 255, 0`（大多数网络都是这个） |
| LOCAL_IP | `192, 168, 1, 100`（**前三段和网关一样，最后一段自己挑一个没人用的**） |
| DNS2 | `223, 5, 5, 5`（阿里公共 DNS，一般不用改） |

**LOCAL_IP 最后一段怎么挑**：建议用 100、150、200 这类，避开路由器已经分出去的地址。如果连不上，换成 .101、.102 再试。

### 常见网络的网段对照

| 网络类型 | 网关通常是 | LOCAL_IP 就写 |
|---------|-----------|--------------|
| 小米路由器 | 192.168.31.1 | 192.168.31.100 |
| TP-Link / 多数家用路由 | 192.168.0.1 或 192.168.1.1 | 对应段的 .100 |
| 安卓手机热点 | 192.168.43.1 | 192.168.43.100 |
| iPhone 热点 | 172.20.10.1 | 172.20.10.100 |
| 校园网 / 公司网 | 看 ipconfig（常见 10.x 网段） | 按网关前三段填 |

## 四、方案 B：不用固定 IP（在陌生网络里更省事）

比赛现场的网络不是你能控制的，**网段、是否允许静态 IP、有没有设备隔离都不知道**。这时候让路由器自动分配 IP 更稳。

**做法：把下面这些行前面加 `//` 注释掉**

```cpp
// IPAddress LOCAL_IP(192, 168, 1, 100);
// IPAddress GATEWAY(192, 168, 1, 1);
// IPAddress SUBNET(255, 255, 255, 0);
// IPAddress DNS1(192, 168, 1, 1);
// IPAddress DNS2(223, 5, 5, 5);
```

同时把 `setup()` 里的这一行也注释掉：

```cpp
// WiFi.config(LOCAL_IP, GATEWAY, SUBNET, DNS1, DNS2);
```

这样 ESP32 会通过 DHCP 自动获取地址，**烧录后从串口打印里看它拿到了什么 IP**，用那个 IP 访问网页。

缺点：IP 每次可能不一样，得看串口。

## 五、改完怎么验证

1. **烧录**，打开串口监视器（115200）
2. 看到这两行才算成功：

```
正在连接 WiFi: 你的WiFi名字
连接成功！IP 地址：192.168.1.100
```

3. 电脑 ping 一下：`ping 192.168.1.100`（换成你实际的 IP）
4. 浏览器打开：`http://192.168.1.100/`
5. 或者用 mDNS：`http://esp32flow.local/`（不用记 IP，但有些系统不支持）

## 六、连不上怎么排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 串口一直打点，30 秒后重启 | SSID 或密码错 | 检查大小写、有没有空格；SSID 要和手机搜到的一字不差 |
| 同上 | 连的是 **5GHz** 频段 | ESP32 **只支持 2.4GHz**，去路由器把 2.4G 和 5G 分开命名，连 2.4G 那个 |
| 串口显示"连接成功"，但电脑打不开网页 | 固定 IP 写错（比如写成了 `192.168.1.100` 这种带点格式） | 改成 `192, 168, 1, 100` 四段格式 |
| 串口显示"连接成功"，但 ping 不通、网页打不开 | **路由器的 AP 隔离**（客户端之间禁止互访），校园网/公共 WiFi 很常见 | 换手机热点试；或在路由器里关闭"AP 隔离/客户端隔离" |
| 电脑能 ping 通，浏览器打不开 | 浏览器缓存 / 代理软件 | Ctrl+F5 强刷；关掉代理，或用无痕窗口 |
| 串口里 IP 不是你想的那个 | NVS 或 DHCP 分配了别的地址 | 以串口打印的 IP 为准 |
| 静态 IP 冲突 | 挑的最后一段被别的设备占了 | 换 .101 / .102 再试 |

### 两个 ESP32 环境的常见坑

1. **安卓手机热点**：默认可能开了"客户端隔离"，ESP32 和电脑都用热点时互访不了，去热点设置里关掉。
2. **校园网**：常有网页认证和 MAC 绑定，ESP32 这种没浏览器的设备通常连不上，**建议用手机热点或自己的路由器**。

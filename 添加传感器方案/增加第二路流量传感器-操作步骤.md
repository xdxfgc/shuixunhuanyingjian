## 第 1 步：选引脚

### 现在已占用的引脚（不能再用）

| 引脚 | 用途 |
|------|------|
| D34 | 流量 1（中断输入） |
| D32 | 水泵继电器 |
| D26 | 加热继电器 |
| D27 | 水温 1（DS18B20） |
| D25 | 水温 2（DS18B20） |
| D33 | 压力传感器（ADC1） |
| D23 | 超声波 Trig |
| D18 | 超声波 Echo |
| D21 / D22 | 光照 I2C（SDA / SCL） |

### 可以用的引脚

**推荐：D19**（本教程按 D19 写，换成别的脚时把代码里的 `19` 改掉即可）

其他可用：**D4、D5、D13、D14**（D16 / D17 也可以，但如果你的板子是带 PSRAM 的 WROVER 型号就别用）

### 选脚要注意的三件事

1. **流量计只需要「输入 + 中断」**，所以大部分 GPIO 都能用，包括 D35 / D36 / D39 这类只能输入的脚。
2. **但千万别选 D35 / D36 / D39** —— 这三个脚在 `config.h` 的 ADC 接线自检列表里（`ADC_DEBUG_DUMP`）。一旦你把自检打开，`analogRead()` 会解除该脚的中断，流量就会永远读 0（**D34 就踩过这个坑**）。所以选**双向数字脚**最安全。
3. **避开**：D0 / D2 / D5 / D12 / D15（启动脚，上电瞬间电平会影响启动；其中 **D5 要求上电为高电平**，流量计信号线做不到，**不要用 D5**）、D6~D11（接内部 Flash，绝对不能用）、D1 / D3（串口 TX/RX，烧录打印要用）。

## 第 2 步：接线

和第一路完全一样的接法，只是信号线换到 D19：

| 传感器线 | 接到哪里 |
|---------|---------|
| 红（VCC） | **5V**（外部电源也行，但负极必须和 ESP32 共地） |
| 黑（GND） | **GND**（和 ESP32 共地） |
| 黄（信号） | **10kΩ 串到 D19**，D19 再接 **20kΩ 到 GND** |

```
传感器黄线 ──[10kΩ]──┬── D19
                     │
                  [20kΩ]
                     │
                    GND
```

### 为什么必须加分压

YF-S401 用 5V 供电时，信号高电平接近 **5V**，而 ESP32 的 GPIO **只耐受 3.3V**，直连会烧脚。
加了这个分压后：`5V × 20/(10+20) ≈ 3.33V`，正好落在安全范围。

### 水管方向

传感器外壳上的箭头要和实际水流方向一致，装反读数不准。

## 第 3 步：新建 flow_sensor2.cpp

### 操作

1. 打开文件夹 `D:\水循环\YF-S401_flow`
2. 把 `flow_sensor.cpp` **复制**一份，重命名为 **`flow_sensor2.cpp`**
3. 用下面这份内容**整个替换**掉新文件里的内容

### 文件内容

```cpp
// ============================================================
// 第二路流量传感器模块（YF-S401 #2）
// 负责：中断计数、每 1 秒结算瞬时流量、累计水量、开机清零
// 接线：红->5V  黑->GND  黄(信号)->10kΩ 串到 D19，D19 再接 20kΩ 到 GND
// ============================================================
#include "config.h"

// 中断回调：只计数器，越短越好
static void IRAM_ATTR pulseISR2() {
  pulseCount2++;
}

void initFlowSensor2() {
  pinMode(FLOW2_PIN, INPUT);
  attachInterrupt(digitalPinToInterrupt(FLOW2_PIN), pulseISR2, RISING);
  Serial.println("YF-S401 #2 流量传感器初始化完成（D19，分压接入，上升沿计数）");
  lastPulseCount2 = readPulseCount2();
  lastSampleMs2 = millis();
}

// 读取当前脉冲计数（关中断再读，避免读到一半被 ISR 打断）
unsigned long readPulseCount2() {
  noInterrupts();
  unsigned long val = pulseCount2;
  interrupts();
  return val;
}

// 结算一次：根据窗口内脉冲数换算瞬时流量和累计量
void sampleFlow2() {
  unsigned long now = millis();
  unsigned long cnt = readPulseCount2();

  // 窗口用时（避免时钟回跳 / 首次为 0）
  unsigned long windowMs = (now >= lastSampleMs2) ? (now - lastSampleMs2) : 0;
  unsigned long delta = cnt - lastPulseCount2;

  if (windowMs > 0) {
    float windowSec = windowMs / 1000.0;
    // 瞬时流量(L/min) = 窗口内脉冲数 / (系数 × 窗口秒数)
    lastFlowRate2 = delta / (PULSES_PER_LITER2 * windowSec);
    // 累计水量 += 瞬时流量 × 窗口分钟数
    totalLiters2 += lastFlowRate2 * (windowSec / 60.0);
  } else {
    lastFlowRate2 = 0.0;
  }

  lastWindowPulses2 = delta;
  lastWindowMs2 = windowMs;
  lastPulseCount2 = cnt;
  lastSampleMs2 = now;

  // ★ 如果希望第二路也能触发「定量浇水自动关泵」，把下面这段的注释去掉：
  // if (pumpTargetLiters > 0 && totalLiters2 >= pumpTargetLiters) {
  //   if (pumpState) {
  //     setPump(false);
  //     Serial.println("第二路达到设定水量，自动关闭水泵");
  //   }
  // }
}

// 清空第二路累计过水总量
void resetTotal2() {
  noInterrupts();
  pulseCount2 = 0;
  interrupts();
  lastPulseCount2 = 0;
  lastSampleMs2 = millis();
  totalLiters2 = 0.0;
  lastFlowRate2 = 0.0;
  lastWindowPulses2 = 0;
  lastWindowMs2 = 0;
}
```

> 说明：默认**不做**自动关泵（因为你可能只是想监测第二条支路的水量）。想要就取消注释那一段。

## 第 8 步：标定系数

### 先理解这个系数是什么

代码里的 `PULSES_PER_LITER2` **名字有点误导**，它其实不是"每升脉冲数"，而是：

> **每 1 L/min 对应的每秒脉冲数**

换算关系：

```
每升脉冲数 ÷ 60 = 代码里的系数
```

例如 YF-S401 理论值是每升 450 个脉冲 → `450 ÷ 60 = 7.5`，所以默认填 7.5。

### 实测标定方法（推荐做一次）

1. 接好管子，准备一个有刻度的容器
2. 让**正好 1 升水**流过第二路传感器
3. 看串口打印的「脉冲2」累计值，或者把一升水全流完后的总脉冲数记下来（记作 **N**）
4. 算出新系数：`系数 = N ÷ 60`

举例：如果 1 升水一共数到 480 个脉冲 → `480 ÷ 60 = 8.0`，就把 `PULSES_PER_LITER2` 改成 `8.0`。

### 简化做法

也可以用第一路的标准验证：同一桶水分两次过两个传感器，看两路的累计水量是否接近。差得多就说明第二路系数要调。

## 常见报错与坑

| 现象 / 报错 | 原因 | 解决 |
|------------|------|------|
| `redefinition of 'xxx'` | 名字没改全，两个文件里有同名变量或函数 | 对照第 3 步，把所有名字都加上 `2` 后缀 |
| `undefined reference to 'pulseCount2'` | config.h 里 `extern` 了，但主文件没定义 | 做第 5.1 步 |
| `'FLOW2_PIN' was not declared` | config.h 里忘了加引脚宏 | 做第 4.1 步 |
| `'sampleFlow2' was not declared` | config.h 里忘了加函数声明 | 做第 4.2 步 |
| 编译通过但脉冲一直是 0 | ① 分压没接好 ② 传感器装反 ③ **该引脚被 `analogRead()` 读过** | 先查接线；再确认该脚没出现在任何 ADC 自检里（D34 踩过这个坑） |
| 流量数值明显偏大/偏小 | 系数不对 | 按第 8 步实测标定 |
| 数值乱跳 | 没共地 / 水泵电机干扰 | 检查共地；传感器电源和电机电源分开 |
| 接上就烧脚 | 信号线直连 5V 没分压 | 必须加 10kΩ + 20kΩ 分压 |

### 两条铁律

1. **任何 `analogRead(引脚)` 都会把那个脚从数字中断模式切走。** 你的 ADC 自检里绝对不要读流量计所在引脚。
2. **每个新传感器的引脚必须唯一**，不能和表里任何一个已占用脚重复。

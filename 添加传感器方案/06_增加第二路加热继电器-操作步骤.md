# 增加第二路加热继电器 · 操作步骤

> 适用工程：`D:\水循环\YF-S401_flow`
> 现状：已有 D26（加热继电器 1）
> 目标：再加一路继电器控制第二个加热模块，接 **D16**，提供 `/api/heater2/on` 等接口

---

## 和"增加第二路水泵继电器"几乎一样

继电器**不需要在 `loop()` 里轮询**，只改 4 个地方：新建 `heater2.cpp` → 改 `config.h` → 改主文件（只加变量和 setup 初始化）→ 改 `web_server.cpp`（可选）。

---

## 第 1 步：选引脚

**推荐 D16**（任意双向 GPIO 都行，不能是 D34~D39 输入专用脚）。

其他可用：D4、D5、D13、D14、D17、D19

⚠️ 如果你的 ESP32 是**带 PSRAM 的 WROVER 型号**，D16 / D17 被 PSRAM 占用了，那就改用 D4 或 D5。

避开：D0 / D2 / D5 / D12 / D15（启动脚；**D5 要求上电为高电平**，继电器 IN 达不到，**不要用 D5**）、D6~D11（接 Flash）。

---

## 第 2 步：接线

| 继电器端子 | 接到哪里 |
|-----------|---------|
| **DC+** | **5V**（或按你继电器模块的额定电压：12V 模块就接 12V；**别把 5V 模块接 12V，会烧**） |
| **DC-** | GND（和 ESP32 共地） |
| **IN** | **D16** |

负载侧（加热回路）：

- 加热电源正 → 继电器 **COM**
- 继电器 **NO** → 加热模块正极
- 加热模块负极 → 加热电源负极
- **NC 空着不接**

⚠️ **继电器的线圈供电和加热负载的供电要分开考虑**：加热模块功率大，一定要用**独立电源**，电流只走 COM/NO，绝不经过 ESP32。

⚠️ 跳线帽极性和 `HEATER2_ACTIVE_HIGH` 必须一致：H → 写 `1`，L → 写 `0`。

---

## 第 3 步：新建 heater2.cpp

复制 `heater.cpp`，重命名为 **`heater2.cpp`**，内容整个替换为：

```cpp
// ============================================================
// 第二路加热继电器模块（D16）
// 负责：初始化（上电默认关）和按触发极性开关第二个加热模块
//
// 接线：D16 -> 继电器 IN；继电器线圈用独立电源；
//       加热模块 正/负 接继电器 COM/NO，随继电器吸合而通电
// ============================================================
#include "config.h"

void initHeaterRelay2() {
  pinMode(HEATER2_PIN, OUTPUT);
  setHeater2(false);        // 上电默认关闭加热
  Serial.println("加热继电器 #2 初始化完成（D16，上电默认关闭）");
}

// 控制第二个加热模块（按 HEATER2_ACTIVE_HIGH 极性）
void setHeater2(bool on) {
  heaterState2 = on;
#if HEATER2_ACTIVE_HIGH
  digitalWrite(HEATER2_PIN, on ? HIGH : LOW);
#else
  digitalWrite(HEATER2_PIN, on ? LOW : HIGH);
#endif
  Serial.printf("加热2%s\n", on ? "已开启" : "已关闭");
}
```

## 第 4 步：改 config.h

### 4.1 加引脚宏和变量声明

找到加热那一段（`extern bool heaterState;` 附近），在下面加：

```cpp
// ---------------- 加热模块 #2 ----------------
#define HEATER2_PIN 16            // D16，第二个加热继电器信号线 IN
#define HEATER2_ACTIVE_HIGH 1     // 1=高电平触发(跳线帽在H)；0=低电平触发(跳线帽在L)
extern bool heaterState2;         // 加热2 当前状态：true=开
```

### 4.2 加函数声明

找到：

```cpp

```

在下面加：

```cpp
// 第二路加热继电器模块
void initHeaterRelay2();
void setHeater2(bool on);
```

### 4.3 加接口声明（做第 6 步才需要）

```cpp

void handleHeater2Toggle();

```

## 第 6 步：改 web_server.cpp（要接口才做）

**6.1 handleData() 里加字段**（在 `"heater"` 那行后面）

```cpp
  json += "\"heater2\":" + String(heaterState2 ? "true" : "false") + ",";
```

**6.2 新增四个接口函数**（在 `handleHeaterState()` 下面）

```cpp
// GET /api/heater2/on —— 开第二个加热
void handleHeater2On() {
  setHeater2(true);
  sendJson(200, "{\"status\":\"ok\",\"heater2\":true}");
}

// GET /api/heater2/off —— 关第二个加热
void handleHeater2Off() {
  setHeater2(false);
  sendJson(200, "{\"status\":\"ok\",\"heater2\":false}");
}

// GET /api/heater2/toggle —— 切换第二个加热
void handleHeater2Toggle() {
  setHeater2(!heaterState2);
  String json = "{\"status\":\"ok\",\"heater2\":" + String(heaterState2 ? "true" : "false") + "}";
  sendJson(200, json);
}

// GET /api/heater2/state —— 查询第二个加热状态
void handleHeater2State() {
  String json = "{\"heater2\":" + String(heaterState2 ? "true" : "false") + "}";
  sendJson(200, json);
}
```

**6.3 registerRoutes() 里注册**（在 `/api/heater/state` 那行附近）

```cpp
  server.on("/api/heater2/on", handleHeater2On);
  server.on("/api/heater2/off", handleHeater2Off);
  server.on("/api/heater2/toggle", handleHeater2Toggle);
  server.on("/api/heater2/state", handleHeater2State);
```

**6.4 网页按钮（可选）**

```cpp
  html += "<p>加热2状态：<b id='heater2'>--</b></p>";
  html += "<button onclick=\"doHeater2(1)\">开加热2</button> ";
  html += "<button onclick=\"doHeater2(0)\">关加热2</button></p>";
```

JS 要分**两个地方**加（⚠️ 加错位置按钮会点不动，见下面的说明）：

**（1）显示更新** —— 放进 `refresh()` 里面。找到 `var h=document.getElementById('heater');` 那两行，在下面加：

```cpp
          "var h2=document.getElementById('heater2');"
          "h2.innerText=d.heater2?'加热中':'已停止';h2.style.color=d.heater2?'orange':'gray';"
```

**（2）控制函数** —— 必须放在 `refresh()` 函数**外面**。找到 `function doHeater(on){...}` 那一行，在它旁边加：

```cpp
          "function doHeater2(on){fetch('/api/heater2/'+(on?'on':'off')).then(refresh);}"
```

> ⚠️ **为什么必须分开写**：按钮用的是 `onclick="doHeater2(1)"`，只能调用**全局函数**。混在上面那段里就会被定义在 `refresh()` 回调**内部**，按钮点击时报 `doHeater2 is not defined`，**点了没反应**。

## 常见坑

| 现象 | 原因 |
|------|------|
| 代码说"已开启"但继电器不响 | ① DC+ 没接够电压 ② 极性反了 ③ IN 接错脚 |
| 一上电加热就开 | 极性反了（跳线帽 L 但代码写 1），或者该脚上电时有电平，可加 10kΩ 下拉到 GND |
| 继电器乱跳 | 没共地 |
| 一加热板子就重启 | 加热模块从 ESP32 取电了，必须独立电源 |
| 触点很快烧坏 | 加热负载电流超过继电器触点额定值，要换更大电流的继电器或固态继电器 |

## ⚠️ 安全提醒

加热模块如果功率较大（几百瓦以上），**不要用这种小继电器模块直接控制**，触点会粘连或烧毁，可能持续通电引发危险。大功率场合应使用**固态继电器（SSR）**或接触器，并且要有人身和设备安全设计（过温保护、干烧保护）。

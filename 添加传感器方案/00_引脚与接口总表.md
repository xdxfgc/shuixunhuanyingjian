## 一、已使用的引脚（共 12 个）

### 传感器部分

| 引脚 | 接什么 | 供电 | 信号处理 |
|------|--------|------|---------|
| **D34** | YF-S401 流量传感器（信号） | 红→5V | 黄线 →10kΩ→ D34 →20kΩ→ GND（分压） |
| **D27** | DS18B20 水温 1 | 红→3.3V | 黄线→D27，**需 4.7kΩ 上拉**到 3.3V |
| **D25** | DS18B20 水温 2 | 红→3.3V | 黄线→D25，**需 4.7kΩ 上拉**到 3.3V |
| **D33** | 压力传感器 HK12-P220（0-1MPa，5V） | 红→5V | 黄线 →10kΩ→ D33 →20kΩ→ GND（分压） |
| **D23** | 超声波 Trig | VCC→5V | 数字输出，直接接 |
| **D18** | 超声波 Echo | — | Echo →1kΩ→ D18 →2kΩ→ GND（分压） |
| **D21** | GY-302 光照 SDA | VCC→3.3V | I2C 数据线 |
| **D22** | GY-302 光照 SCL | — | I2C 时钟线（模块自带上拉） |

### 执行器部分

| 引脚 | 接什么 | 接线要点 |
|------|--------|---------|
| **D32** | 继电器 1（水泵） | DC+→5V，DC-→GND，IN→D32，跳线帽 **H** |
| **D14** | 继电器 2（水泵2） | DC+→5V，DC-→GND，IN→D14，跳线帽 **H** |
| **D26** | 加热继电器 1 | IN→D26，线圈独立电源，加热模块接 COM/NO |
| **D16** | 加热继电器 2 | IN→D16，线圈独立电源，加热模块接 COM/NO |

### 电源汇总

- **5V 供电**：流量计红线、压力传感器红线、超声波 VCC、4 个继电器的 DC+
- **3.3V 供电**：两个 DS18B20 红线、GY-302 VCC，以及两个 4.7kΩ 上拉电阻
- **GND**：以上全部 + 水泵电源负极 + 加热电源负极，**必须和 ESP32 共地**
- **水泵 / 加热负载**：用**独立电源**，只经过继电器 COM/NO，绝不能从 ESP32 取电

## 三、还能用的引脚

| 引脚 | 可用性 |
|------|--------|
| **D4、D13、D17、D19** | ✅ 普通双向脚，可接继电器、数字传感器、OneWire |
| **D35、D36、D39** | ⚠️ 输入专用，只能做**模拟输入**（可接压力等模拟传感器） |
| D0、D2、D5、D12、D15 | ❌ strapping 启动脚，见下面说明 |
| D1、D3 | ❌ 串口 TX/RX，烧录和串口打印要用 |
| D6 ~ D11 | ❌ 接内部 Flash，碰了板子起不来 |

## 四、四条铁律（每次加新模块都要检查）

1. **`analogRead(引脚)` 会抢走那个脚的中断和数字功能。** 任何做中断/脉冲测量的脚（流量计）绝不能出现在 ADC 自检里——D34 已经踩过一次这个坑。
2. **模拟量传感器（压力、模拟光照）必须用 ADC1**：D32、D33、D34、D35、D36、D37、D38、D39。**不能用 ADC2**（D0/D2/D4/D12/D13/D14/D15/D25/D26/D27），WiFi 一开就读不准。
3. **OneWire（DS18B20）、I2C、继电器不能用 D34~D39**（输入专用脚，不能输出、不能拉低总线）。但做**纯输入**的脉冲测量可以。
4. **每个 5V 供电的传感器，信号线都要分压**（10kΩ 串 + 20kΩ 到 GND），并且**所有电源的 GND 必须和 ESP32 共地**。

## 五、引脚选择的判断流程

```
这个传感器输出什么？
├─ 模拟电压（0~3.3V / 0~5V）   → 必须 ADC1（D32~D39）；接 5V 输出要分压
├─ 脉冲 / 开关量（流量计、霍尔）→ 任意脚；做中断优先选双向脚
├─ 单总线（DS18B20）           → 必须双向脚（不能 D34~D39），要 4.7kΩ 上拉
├─ I2C（BH1750 等）            → 优先共用已有总线 D21/D22，靠地址区分
└─ 执行器（继电器）             → 任意输出脚，避开启动脚
```

### 关于 strapping（启动）脚：D0 / D2 / D5 / D12 / D15

这 5 个脚在上电瞬间的电平会影响 ESP32 启动，原则是"能用，但要保证上电时的电平正确"：

| 引脚 | 上电要求 | 实际影响 |
|------|---------|---------|
| D0 | 高电平才进正常启动 | 被拉低会进烧录模式，**建议避开** |
| D2 | 低电平 | 常与板载 LED 冲突，**建议避开** |
| **D5** | 高电平（内部默认上拉） | 只影响 SDIO 从机时序，**普通开发板正常使用没问题** |
| D12 | 低电平 | 拉高会导致 Flash 电压不对，**必须避开** |
| D15 | 高电平 | 被拉低会进调试输出模式，**建议避开** |

## 七、通用套路：加任何新模块都是改 5 个地方

1. **新建一个 .cpp 文件**（复制同类型模块，改名 + 加后缀）
2. **改 `config.h`**：加引脚宏、加 `extern` 变量声明、加函数声明
3. **改主文件 `YF-S401_flow.ino`**：定义全局变量、`setup()` 里初始化、`loop()` 里轮询
4. **改 `web_server.cpp`**（可选）：加 JSON 字段、加 handler、注册路由、网页显示
5. **编译烧录 + 测试**

**最容易忘的两件事**：

- `config.h` 里写了 `extern`，就**必须在主文件里定义一次**（否则报 `undefined reference`）
- 复制文件后，里面**所有**变量名、函数名都要加后缀，否则报 `redefinition`

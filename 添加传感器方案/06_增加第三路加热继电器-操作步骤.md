# 增加第三路加热继电器 · 操作步骤

> 适用工程：`D:\水循环\YF-S401_flow`
> 现状：已有 **D26**（加热继电器 1）和 **D16**（加热继电器 2）
> 目标：再加一路加热继电器，接 **D4**，提供 `/api/heater3/on` 等接口

---

## 继电器和传感器不一样的地方

继电器**不需要在 `loop()` 里轮询**——它只在"你点按钮 / 调接口"的时候动一下。所以只改 4 个地方：

1. 新建 `heater3.cpp`
2. 改 `config.h`
3. 改主文件（**只需要定义变量 + `setup()` 里初始化**，`loop` 不用动）
4. 改 `web_server.cpp`（可选，要接口和网页按钮才做）

---

## 第 1 步：选引脚

**推荐 D4。**

你现在的引脚占用情况：

| 已占用 | 用途 |
|--------|------|
| D34 | 流量 1 |
| D32 | 继电器 1（水泵） |
| D14 | 继电器 2（水泵2） |
| **D26** | **加热继电器 1** |
| **D16** | **加热继电器 2** |
| D27 / D25 | 水温 1 / 2 |
| D33 | 压力 |
| D23 / D18 | 超声波 Trig / Echo |
| D21 / D22 | 光照 I2C |

继电器 IN 是**数字输出**信号，要求：**双向 GPIO、不能是 D34~D39**（输入专用脚）。

可用清单：

| 引脚 | 说明 |
|------|------|
| **D4** | **推荐**。普通双向脚 |
| D13 | 普通双向脚，可用 |
| D17 | 普通双向脚；带 PSRAM 的 **WROVER** 型号不能用 |
| D19 | 普通双向脚，可用 |
| ~~D35 / D36 / D39~~ | ❌ 输入专用脚，输出不了电平 |
| ~~D5~~ | ❌ strapping 启动脚，要求上电高电平，继电器 IN 达不到 |
| ~~D0 / D2 / D12 / D15~~ | ❌ 其他 strapping 脚，避开 |
| ~~D6~D11~~ | ❌ 接内部 Flash，绝对不能用 |

> **注意脚位冲突**：`00_引脚与接口总表.md` 里给其他待加模块也预留了脚——
> 流量2 用 D19、超声波2 用 D4/D13、继电器3 用 D17。
> 如果你**不打算加**某个模块，它预留的脚就能挪给这里的加热3（把代码里的 `4` 换成对应号即可）。

## 第 2 步：接线

| 继电器端子 | 接到哪里 |
|-----------|---------|
| **DC+** | **5V**（或按模块额定电压；5V 模块千万别接 12V） |
| **DC-** | GND（**必须和 ESP32 共地**，否则继电器乱跳） |
| **IN** | **D4** |

负载侧（加热回路）：

- 加热电源正 → 继电器 **COM**
- 继电器 **NO** → 加热模块正极
- 加热模块负极 → 加热电源负极
- **NC 空着不接**

⚠️ **加热模块功率大，必须用独立电源**，电流只走 COM/NO，绝不经过 ESP32。

⚠️ **跳线帽要和代码里的极性宏一致**：跳线帽在 **H** → `HEATER3_ACTIVE_HIGH` 写 `1`；在 **L** → 写 `0`。

> 可选加固：在 IN 和 GND 之间加一个 **10kΩ 下拉电阻**，避免上电瞬间继电器抖一下。

## 第 3 步：新建 heater3.cpp

在文件夹 `D:\水循环\YF-S401_flow` 里，复制 `heater2.cpp`，重命名为 **`heater3.cpp`**，内容整个替换为：

```cpp
// ============================================================
// 第三路加热继电器模块（D4）
// 负责：初始化（上电默认关）和按触发极性开关第三个加热模块
//
// 接线：DC+ -> 5V（或模块额定电压），DC- -> GND（必须和 ESP32 共地），IN -> D4
//       加热模块电源独立，接继电器 COM/NO，不要从 ESP32 取电
//       ⚠️ 跳线帽极性和 HEATER3_ACTIVE_HIGH 必须一致（H 对应 1，L 对应 0）
// ============================================================
#include "config.h"

void initHeaterRelay3() {
  pinMode(HEATER3_PIN, OUTPUT);
  setHeater3(false);        // 上电默认关闭加热
  Serial.println("加热继电器 #3 初始化完成（D4，上电默认关闭）");
}

// 控制第三个加热模块（按 HEATER3_ACTIVE_HIGH 极性）
void setHeater3(bool on) {
  heaterState3 = on;
#if HEATER3_ACTIVE_HIGH
  digitalWrite(HEATER3_PIN, on ? HIGH : LOW);
#else
  digitalWrite(HEATER3_PIN, on ? LOW : HIGH);
#endif
  Serial.printf("加热3%s\n", on ? "已开启" : "已关闭");
}
```

## 第 6 步：改 web_server.cpp（要接口和按钮才做）

### 6.1 handleData() 里加字段

找到：

```cpp
  json += "\"heater2\":" + String(heaterState2 ? "true" : "false") + ",";
```

在它下面加：

```cpp
  json += "\"heater3\":" + String(heaterState3 ? "true" : "false") + ",";
```

> 同样可以在 `handleHealth()` 里加一份，非必须。

### 6.2 新增四个接口函数

找到 `handleHeater2State()` 那个函数，在它下面加：

```cpp
// GET /api/heater3/on —— 开第三个加热
void handleHeater3On() {
  setHeater3(true);
  sendJson(200, "{\"status\":\"ok\",\"heater3\":true}");
}

// GET /api/heater3/off —— 关第三个加热
void handleHeater3Off() {
  setHeater3(false);
  sendJson(200, "{\"status\":\"ok\",\"heater3\":false}");
}

// GET /api/heater3/toggle —— 切换第三个加热
void handleHeater3Toggle() {
  setHeater3(!heaterState3);
  String json = "{\"status\":\"ok\",\"heater3\":" + String(heaterState3 ? "true" : "false") + "}";
  sendJson(200, json);
}

// GET /api/heater3/state —— 查询第三个加热状态
void handleHeater3State() {
  String json = "{\"heater3\":" + String(heaterState3 ? "true" : "false") + "}";
  sendJson(200, json);
}
```

### 6.3 registerRoutes() 里注册

找到：

```cpp
  server.on("/api/heater2/state", handleHeater2State);
```

在它下面加：

```cpp
  server.on("/api/heater3/on", handleHeater3On);
  server.on("/api/heater3/off", handleHeater3Off);
  server.on("/api/heater3/toggle", handleHeater3Toggle);
  server.on("/api/heater3/state", handleHeater3State);
```

### 6.4 网页按钮

**（1）按钮和状态行** —— 在 `handleRoot()` 里，找到：

```cpp
  html += "<button onclick=\"doHeater2(0)\">关加热2</button></p>";
```

在它下面加：

```cpp
  html += "<p>加热3状态：<b id='heater3'>--</b></p>";
  html += "<button onclick=\"doHeater3(1)\">开加热3</button> ";
  html += "<button onclick=\"doHeater3(0)\">关加热3</button></p>";
```

**（2）显示更新** —— 放进 `refresh()` 里面。找到：

```cpp
          "h2.innerText=d.heater2?'加热中':'已停止';h2.style.color=d.heater2?'orange':'gray';"
```

在它下面加：

```cpp
          "var h3=document.getElementById('heater3');"
          "h3.innerText=d.heater3?'加热中':'已停止';h3.style.color=d.heater3?'orange':'gray';"
```

**（3）控制函数** —— 必须放在 `refresh()` 函数**外面**。找到：

```cpp
          "function doHeater2(on){fetch('/api/heater2/'+(on?'on':'off')).then(refresh);}"
```

在它旁边加：

```cpp
          "function doHeater3(on){fetch('/api/heater3/'+(on?'on':'off')).then(refresh);}"
```

> ⚠️ **为什么第 (3) 步必须放在外面**：按钮用的是 `onclick="doHeater3(1)"`，只能调用**全局函数**。混在 `refresh()` 里面的话，函数只在那个回调内部可见，点击时会报 `doHeater3 is not defined`，**点了完全没反应**。
> 判断方法：`function doHeater(...)`、`function doHeater2(...)` 这两行的位置就是"外面"。

## 常见坑

| 现象 | 原因 |
|------|------|
| 代码打印"已开启"但继电器不咔哒 | ① DC+ 电压不够或没接 ② 跳线帽极性和 `HEATER3_ACTIVE_HIGH` 反了 ③ IN 线没接对脚 |
| 一上电加热就开 | 极性反了（把宏的 1 改成 0，或跳线帽从 H 拨到 L），或者加个 10kΩ 下拉 |
| 继电器随机乱跳 | **没共地**（继电器 DC- 和 ESP32 GND 必须接一起） |
| 一加热板子就重启 | 加热模块从 ESP32 取电了，必须用独立电源 |
| 网页按钮点了没反应，但直接访问网址能动作 | JS 的 `function doHeater3(...)` 加进了 `refresh()` 里面，要挪到外面（见 6.4 第 (3) 步） |
| 编译报 `redefinition` | 复制文件后变量名/函数名没全改成 `3` 后缀 |
| 编译报 `undefined reference to 'heaterState3'` | `config.h` 里声明了，但主文件没定义（见 5.1） |
| 板子开不了机 / 反复重启 | 引脚选到了 strapping 脚（D0/D2/D5/D12/D15），换 D4 等普通脚 |

## ⚠️ 安全提醒

加热模块如果功率较大（几百瓦以上），**不要用这种小继电器模块直接控制**——触点会粘连或烧毁，可能持续通电引发危险。大功率场合应使用**固态继电器（SSR）**或接触器，并且要有过温保护、干烧保护。

# 增加第二个压力传感器（0-1MPa #2）· 操作步骤

> 适用工程：`D:\水循环\YF-S401_flow`
> 现状：已有 D33（压力 1）
> 目标：再加一路压力，接 **D35**，提供 `/api/pressure2`

---

## 第 1 步：选引脚（这一步最关键）

压力传感器是**模拟输出**，必须接 **ADC1** 的脚，即 **D32 / D33 / D34 / D35 / D36 / D37 / D38 / D39**。

⚠️ **绝对不能用 ADC2 的脚**（D0 / D2 / D4 / D12 / D13 / D14 / D15 / D25 / D26 / D27）——ESP32 的 ADC2 和 WiFi 冲突，WiFi 一开就读不出正确值。

你现在的空闲 ADC1 脚：**D35、D36、D39**（都是输入专用脚，做模拟输入正合适）。

**推荐 D35。** 另外：D35 / D36 / D39 也出现在 ADC 自检列表里，如果以后你把 `ADC_DEBUG_DUMP` 打开，它们会被 `analogRead` 占用——但对压力传感器来说没影响（本来就在读模拟），**有影响的是别把流量计那类中断传感器放这几个脚上**。

---

## 第 2 步：接线

| 传感器线 | 接到哪里 |
|---------|---------|
| 红（VCC） | **5V**（可用外部电源，但负极必须和 ESP32 共地） |
| 黑（GND） | GND |
| 黄（信号） | **10kΩ 串到 D35**，D35 再接 **20kΩ 到 GND** |

```
传感器黄线 ──[10kΩ]──┬── D35
                     │
                  [20kΩ]
                     │
                    GND
```

### 为什么必须分压

5V 供电的这类压力传感器，输出通常是 **0.5~4.5V**，最高 4.5V **超过 ESP32 ADC 的量程（约 3.3V）**，直连会一直读到满值，还可能伤脚。分压后 4.5V 变成 3.0V，正好在范围内。

## 第 3 步：新建 pressure_sensor2.cpp

复制 `pressure_sensor.cpp`，重命名为 **`pressure_sensor2.cpp`**，内容整个替换为：

```cpp
// ============================================================
// 第二路压力传感器模块（0-1MPa 模拟输出，D35）
// 接线：红 -> 5V  黑 -> GND  黄 -> 10kΩ 串到 D35，D35 再接 20kΩ 到 GND
// 换算参数复用第一路的：PRESSURE_V_MIN / PRESSURE_V_MAX / PRESSURE_P_MAX
//   （若第二只传感器量程或输出范围不同，请在 config.h 里单独定义一套）
// ============================================================
#include "config.h"

static unsigned long lastPressureMs2 = 0;
static bool warnedOverRange2 = false;   // ADC 满量程只提示一次，避免刷屏

void initPressureSensor2() {
  pinMode(PRESSURE2_PIN, INPUT);
  analogReadResolution(12);  // 0~4095
  analogSetPinAttenuation(PRESSURE2_PIN, ADC_11db);  // 量程约 0~3.3V
  lastPressure2 = 0.0;
  lastPressureVoltage2 = 0.0;
  lastPressureRaw2 = 0.0;
  lastPressurePinVoltage2 = 0.0;
  pressureOk2 = false;
  Serial.println("压力传感器 #2 初始化完成（D35，0-1MPa 模拟输出）");
}

// 非阻塞轮询：主循环每圈调用一次
void processPressureSensor2() {
  unsigned long now = millis();
  if (now - lastPressureMs2 < PRESSURE_SAMPLE_INTERVAL_MS) return;
  lastPressureMs2 = now;

  // 多次采样取平均，降低 ADC 噪声
  uint32_t sum = 0;
  for (int i = 0; i < PRESSURE_SAMPLES; i++) {
    sum += analogRead(PRESSURE2_PIN);
  }
  float raw = sum / (float)PRESSURE_SAMPLES;

  // 引脚电压 -> 还原成传感器实际输出电压（去掉分压）
  float vPin = raw / 4095.0 * PRESSURE_VREF;
  float vSig = vPin / PRESSURE_DIVIDER_RATIO;

  // 原始值始终记录，方便标定和排查
  lastPressureRaw2 = raw;
  lastPressurePinVoltage2 = vPin;
  lastPressureVoltage2 = vSig;

  // ADC 顶到满量程：多半是分压电阻没接，或传感器输出超范围
  if (raw >= 4090.0) {
    pressureOk2 = false;
    if (!warnedOverRange2) {
      Serial.println("压力#2 ADC 满量程：D35 电压过高，检查 10kΩ+20kΩ 分压电阻是否接好");
      warnedOverRange2 = true;
    }
    return;
  }

  // 合理性判断：太低（断线/未接）或太高视为无效
  if (vSig < 0.3 || vSig > 5.3) {
    pressureOk2 = false;
    return;
  }

  float p = (vSig - PRESSURE_V_MIN) / (PRESSURE_V_MAX - PRESSURE_V_MIN) * PRESSURE_P_MAX;
  if (p < 0) p = 0;
  if (p > PRESSURE_P_MAX) p = PRESSURE_P_MAX;

  lastPressure2 = p;
  pressureOk2 = true;
}
```

> 说明：这里**复用了第一路的换算常量**（`PRESSURE_VREF`、`PRESSURE_V_MIN`、`PRESSURE_V_MAX`、`PRESSURE_P_MAX`、`PRESSURE_DIVIDER_RATIO`、`PRESSURE_SAMPLES`、`PRESSURE_SAMPLE_INTERVAL_MS`），因为两只传感器是同一型号。如果第二只量程不同（比如 0~0.5MPa），要在 config.h 里另建一套 `PRESSURE2_V_MIN` 之类的宏，并把代码里的名字换掉。

## 第 7 步：烧录与测试

串口应打印：

```
压力传感器 #2 初始化完成（D35，0-1MPa 模拟输出）
```

测试网址：`http://192.168.31.100/api/pressure2`

返回类似：

```json
{"value":0.015,"unit":"MPa","ok":true,"raw":186,"pinVoltage":0.150,"voltage":0.560}
```

**空载（不加压）时 `voltage` 应该在 0.5~0.56V 附近**，`value` 在 0.01~0.02 MPa 左右，这是正常的零点偏差（ESP32 ADC 在低压段非线性）。稳定不跳就说明接线对了。

想让空载显示 0.000，把 `voltage` 的实测值填进 `PRESSURE_V_MIN` 做零点校准——但注意**这会同时影响第一路**（因为两路共用这套常量）。如果两路的零点差得多，就给第二路单独建一套宏。

## 常见坑

| 现象 | 原因 |
|------|------|
| `raw` 一直是 4095、`ok` 是 false | 分压没接 / 接错，D35 电压顶到 3.3V |
| `value` 一直是 0 | 传感器没供电，或信号线没接上 |
| 读数忽大忽小乱跳 | 没共地；或电源和水泵共用一路被干扰 |
| 编译报 `'PRESSURE2_PIN' was not declared` | config.h 里忘了加引脚宏 |
| 数值全都不对 | 接到了 ADC2 的脚（比如 D4/D13/D14/D25），必须换回 ADC1 |

# 增加第三路温度传感器（DS18B20 #3）· 操作步骤

> 适用工程：`D:\水循环\YF-S401_flow`
> 现状：已有 **D27（水温 1）** 和 **D25（水温 2）** 两路温度
> 目标：再加一路温度，接 **D5**，提供 `/api/temperature3`

---

## 先看这个：更省事的替代方案

DS18B20 是**单总线**，多个探头可以**全挂在同一根线上**（比如都接 D27，共用一个 4.7kΩ 上拉），靠芯片唯一的 64 位地址区分。

那样**不用新建文件、不用多占引脚、不用多接电阻**，只要在现有 `temp_sensor.cpp` 里按序号取：

```cpp
float t1 = tempSensors.getTempCByIndex(0);   // 第 1 个探头
float t2 = tempSensors.getTempCByIndex(1);   // 第 2 个探头
float t3 = tempSensors.getTempCByIndex(2);   // 第 3 个探头
```

**缺点**：某个探头接触不良掉线时，后面的编号会整体前移，"3 号"可能变成"2 号"。比赛前一定要把线接牢。

如果探头要装在离得远的地方，或者你想让每路的接线和编号一一对应、绝不混淆，就用下面的**独立引脚**方案。

---

## 第 1 步：选引脚

**推荐 D5**。要求：

- 必须是**双向 GPIO**（OneWire 需要把总线拉低再放开），所以**不能用 D34~D39**
- 避开启动脚 D0 / D2 / D12 / D15
- 不能和其他已占用脚重复

⚠️ **其他脚基本都用完了**：D4/D13（超声波2）、D19（流量2）、D14（继电器2）、D16（加热继电器2）
都已经占用，**现在只剩 D17 一个空闲双向脚**（而且 05/06 两份文档也在抢它）。

> **关于 D5**：D5 也属于 ESP32 的 strapping（启动）脚，作用是配置 SDIO 从机时序，**要求上电时为高电平**。DS18B20 的数据线有 4.7kΩ 上拉到 3.3V，上电时本来就是高电平，正好满足要求，所以用 D5 没问题。
> 想完全避开 strapping 脚的话，改用 **D17**（带 PSRAM 的 WROVER 板子不能用 D16/D17）。

---

## 第 2 步：接线

| 探头线 | 接到哪里 |
|-------|---------|
| 红（VCC） | **3.3V**（DS18B20 支持 3.0~5.5V，用 3.3V 最省事） |
| 黑（GND） | GND |
| 黄（数据） | **D5** |

```
3.3V ──[4.7kΩ]──┬── D5
                 │
            DS18B20 黄线
```

⚠️ **必须加 4.7kΩ 上拉电阻**（黄线到 3.3V）。裸探头不自带上拉，只靠 ESP32 内部那 45kΩ 弱上拉能勉强读到，但线一长、旁边有水泵电机干扰就会掉成"无效"。

---

## 第 3 步：新建 temp_sensor3.cpp

复制 `temp_sensor.cpp`，重命名为 **`temp_sensor3.cpp`**，内容整个替换为：

```cpp
// ============================================================
// 第三路温度传感器模块（DS18B20 #3，D5）
// 接线：红 -> 3.3V，黑 -> GND，黄(信号) -> D5 + 4.7kΩ 上拉到 3.3V
// ============================================================
#include "config.h"

static OneWire oneWire3(TEMP3_PIN);
static DallasTemperature tempSensors3(&oneWire3);
static bool sensorFound3 = false;
static bool conversionPending3 = false;
static unsigned long lastRequestMs3 = 0;

void initTempSensor3() {
  // 兜底：开内部弱上拉（约 45kΩ），正常应外接 4.7kΩ
  pinMode(TEMP3_PIN, INPUT_PULLUP);
  tempSensors3.begin();
  sensorFound3 = (tempSensors3.getDeviceCount() > 0);
  tempSensors3.setWaitForConversion(false);   // 非阻塞

  lastWaterTemp3 = NAN;
  tempOk3 = false;

  if (sensorFound3) {
    Serial.printf("DS18B20 #3 温度传感器初始化完成（D5，发现 %d 个）\n",
                  tempSensors3.getDeviceCount());
    tempSensors3.requestTemperatures();
    lastRequestMs3 = millis();
    conversionPending3 = true;
  } else {
    Serial.println("DS18B20 #3 未检测到：检查 D5 接线和 4.7kΩ 上拉电阻");
  }
}

// 非阻塞轮询：主循环每圈调用一次
void processTempSensor3() {
  if (!sensorFound3) return;

  unsigned long now = millis();

  if (!conversionPending3) {
    // 复用第一路的时间常量 TEMP_READ_INTERVAL_MS / TEMP_CONVERSION_MS
    if (now - lastRequestMs3 >= TEMP_READ_INTERVAL_MS) {
      tempSensors3.requestTemperatures();
      lastRequestMs3 = now;
      conversionPending3 = true;
    }
    return;
  }

  if (now - lastRequestMs3 >= TEMP_CONVERSION_MS) {
    conversionPending3 = false;
    float t = tempSensors3.getTempCByIndex(0);
    if (t > -55.0 && t < 125.0 && t != 85.0) {
      lastWaterTemp3 = t;
      tempOk3 = true;
    } else {
      tempOk3 = false;
      Serial.printf("DS18B20 #3 读数异常(%.1f℃)：请检查接线与上拉电阻\n", t);
    }
  }
}
```

> `OneWire.h`、`DallasTemperature.h` 已经在 `config.h` 里统一包含，新文件**不用再 include**。

## 常见坑

| 现象 | 原因 |
|------|------|
| `redefinition of 'oneWire'` | 复制文件后变量名没加 `3` 后缀 |
| `undefined reference to 'lastWaterTemp3'` | config.h 声明了，主文件没定义 |
| 一直"无效" | ① 忘了 4.7kΩ 上拉 ② 引脚接到了 D34~D39（输入专用脚做不了 OneWire）③ 红黑接反（可能烧探头） |
| 读数一直是 85℃ | 通信失败的特征值，检查接线 |
